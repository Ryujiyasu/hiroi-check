# ひろいチェック — 下水道の数量拾い支援

Jw_cad の下水道図面（平面図・縦断図）から、数量計算書の入力シートに入れる値を拾い、図面の中で本来そろう値を突き合わせて誤りの疑いを示し、数量計算書（Excel）を様式の計算式のまま再計算する Web アプリです。

**デモ:** https://ryujiyasu.github.io/hiroi-check/ （「サンプル図面で試す」から始めると流れが分かります）

## 図面を外に出さない

図面の読み取り（[ezjww](https://github.com/monozukuri-ai/ezjww)）も、Excel の計算（文書エンジン [Oxi](https://github.com/Ryujiyasu/oxi)）も、WebAssembly でブラウザの中だけで動きます。サーバーは静的ファイルを配るだけで、図面は受け取りません。

外部に送るのは、利用者が「AIチェック」を押して API キーを入れたときだけです。そのときも送るのは図面の文字データ（文字・座標）と抽出・検算の結果で、線や画像は送りません。数量の計算は AI にさせません。

## できること

| 画面 | 内容 |
|---|---|
| 確認すべき箇所 | 検算で食い違った箇所。押すと図面上の該当文字を枠で示して寄る |
| 入力シート（管きょ）・人孔 | 数量計算書の入力シートに入れる値。セルを押すと、拾った図面上の文字を示す。CSV で保存できる |
| 計算結果 | 数量計算書に値を書き込み、ブラウザの中で再計算した土工計算書と集計。計算済みの xlsx と取込用CSVを保存できる |
| 当初と変更 | 変更図面を追加すると、入力シートの違いと数量の増減を示す。変更の値は数量計算書の下段に入る |
| AIチェック（任意） | 検算の指摘ごとに「図面の誤記」か「読み取りの誤り」かを Claude が判定し、拾い漏れの疑いを探す |

### 突き合わせる内容

- 区間ごとの管底高の差 ＝ 区間距離 × 勾配
- 人孔深 ＝ 地盤高 − 最も低い管底高（接続管を含む）
- 土被り ＝ 地盤高 − 管底高 − 管の外径
- 追加距離 ＝ 区間距離の累計
- 平面図の管路注記（延長・勾配・管径）と縦断図
- 平面図の見出し（L=、N=箇所）と縦断図の合計
- 取付管の本数と汚水ますの数

縦断図の書き方の違い（行の並び・呼び方・全角数字・左が上流か下流か・管底高の左右の書き方・まとめ書き）は自動で吸収します。

## 仮のもの・これから

- **数量計算書は模擬版です。** 入力シートの並びは自治体の様式を参考に再現し、土工計算書・集計の計算式と係数は仮の値です。実際の様式の xlsx と `template/template_map.json`（どの値をどのセルに書くかの対応表）を差し替えれば、その様式の計算式どおりに動きます。
- 人孔・管種のコード（`js/core.mjs` の `MH_CODE`・`PIPE_CODE`）は仮の値です。
- 取込用CSVは集計表をそのまま CSV にしたものです。積算システムの取込仕様に合わせるのはこれからです。
- 横断図・舗装図・人孔構造図からの拾い（基礎材・舗装・バックホウ規格・接続管種など）は未対応です。
- Oxi のビルド済み WebAssembly は約 97MB（文書エンジン全体）で、初回の読み込みに時間がかかります。表計算だけの軽いビルドに置き換える予定です。
- サンプル図面はすべて検証用に作った架空のものです。「豊川市の書き方を再現した図面」も、書き方だけを再現し数値は架空です。

## 構成

| パス | 中身 |
|---|---|
| `js/core.mjs` | 抽出・入力シート・検算・当初と変更の差分（ブラウザと Node の両方で動く） |
| `js/sheet.mjs` | 数量計算書への書き込み・再計算・読み出し（Oxi） |
| `js/render.mjs` | 図面の SVG 表示・拡大移動・根拠の強調 |
| `js/ai.mjs`・`js/ai_prompt.json` | AI チェック（任意） |
| `js/app.mjs` | 画面の制御 |
| `template/` | 模擬版の数量計算書と対応表（`tools/make_template.py` で生成） |
| `vendor/` | ezjww（MIT）、Oxi（MPL-2.0）、Anthropic SDK（MIT）。各ライセンスを同梱 |
| `samples/` | 検証用の架空の図面 |
| `test/` | `parity.mjs`（Python 版の試作との一致確認。試作は非公開）、`e2e.mjs`・`e2e_change.mjs`（ヘッドレス Chrome での通し確認） |

## 手元で動かす

```bash
python3 -m http.server 8765      # http://127.0.0.1:8765/ を開く
```

部品の取り込み直しは `npm install` のあと `node tools/vendor.mjs [Oxi の web ディレクトリ]`。
